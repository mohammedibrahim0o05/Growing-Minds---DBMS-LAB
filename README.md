## 📝 Instructions for Students

1. Fork this repository to your GitHub profile.

2. For each experiment, SQL queries are based on questions generated randomly from Moodle.

3. Complete the question on Moodle.

4. Each experiment folder contains **two Markdown files**:

   - `README.md`
   - `output.md`

### 📖 `README.md`

This file contains:

- 🎯 **Aim**
- 📚 **Theory**
- 📝 **Result**

You **do not need to edit** this file unless instructed.

### 📄 `output.md`

You **must update this file** with your answers and outputs.

For each of the **10 Moodle-generated questions**:

- Paste the **question**
- Write the **SQL query** inside a code block
- Paste a **screenshot or terminal output** below it

5. Commit and push your changes.

6. Create a **Pull Request** to the original repository.
